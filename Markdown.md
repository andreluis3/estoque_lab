## Caminhos e Recursos Verificados

- `ROOT_DIR` resolve para a pasta `inventario`; `IMAGES_DIR` resolve para `assets`, que existe. Os dez arquivos de imagem/ícone consultados estão presentes.
- `main_original.py` usa `logo.ico`; `TelaHenriquePage`, `LogoWidget` e `MenuLateralWidget` procuram `logo_software.png`, `Logo_IPT.png` e os ícones do menu. O caminho baseado em pacote serve para recursos **se eles forem incluídos no bundle**. A documentação do [PyInstaller sobre runtime](https://pyinstaller.org/en/stable/runtime-information.html) confirma que `__file__` aponta para dentro do bundle; em one-file, os dados são extraídos para diretório temporário.
- No ambiente atual, `.` aponta para `\\iptfiles\EN`; a raiz `EstoqueLab`, `app`, `backup` e `planilha_equipamentos` foram encontradas. Isso confirma somente disponibilidade neste computador, não permissões de escrita dos outros clientes.
- O caminho atual do banco e o do `BackupService` resolvem para o mesmo arquivo existente no desenvolvimento. A configuração `caminhos.database` não é usada para determinar `DB_PATH`.
- `DATABASE_DIR`, `PLANILHAS_DIR`, `LOGS_DIR` e `BACKUP_DIR` de `paths.py` não aparecem como fonte comum dos serviços. `BACKUP_DIR` aponta para `inventario/backup`, que não existe atualmente.

- Não executei `criar_backup()`, exportação nem `main()`: escreveriam em banco/diretórios. Também não fiz build. O import da entrada principal foi testado, mas não comprova execução do EXE.
